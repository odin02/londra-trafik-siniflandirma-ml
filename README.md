# Londra Trafik Akışı Sınıflandırma Projesi

## Proje Hakkında
Bu proje, Londra trafik akışı (AADF) verilerini kullanarak yol kategorilerini ve trafik özelliklerini sınıflandırmak amacıyla geliştirilmiştir. 

## Kullanılan Yöntemler & Algoritmalar
* Veri Ön İşleme ve Keşifsel Veri Analizi (EDA)
* Makine Öğrenmesi Sınıflandırma Modelleri:
  * Lojistik Regresyon (Logistic Regression)
  * Karar Ağaçları (Decision Trees)
